ⓘ How to write the list
  • One card per line. Use the card ID printed on the card, e.g. OP05-119.
  • Quantity is optional (default 1): OP05-119 x3, OP05-119 ×3, OP05-119, 3 or OP05-119 3.
  • A plain ID means the regular version. For a special version, add its suffix: OP01-120_p1 (parallel 1), ST02-007_r1 (reprint). OP01-120-p1 works too.
  • DON cards use their full ID, e.g. PRB01-DON-Ace-GOLD. Not sure of an ID? Use the search box above: suggestions show the exact ID of each version.
  • Upper/lower case doesn't matter. Lines that don't match a card stay in the box so you can fix them.
